## 📌 Tentang Prompt Vault

Prompt Vault adalah **web aplikasi** untuk mengoleksi, menyimpan, dan membagikan prompt jailbreak untuk berbagai macam AI seperti **ChatGPT, DeepSeek, Claude, Gemini, Dola**, dan lainnya.

Dibuat oleh **SouGPT** untuk komunitas AI enthusiast yang ingin mengeksplorasi kemampuan AI tanpa batasan.

---

## ✨ Fitur Unggulan

| Fitur | Deskripsi |
|-------|-----------|
| 📚 **Koleksi Prompt** | Puluhan prompt jailbreak siap pakai |
| 🔍 **Pencarian** | Cari prompt berdasarkan judul atau isi |
| 🏷️ **Kategori** | Filter prompt berdasarkan kategori AI |
| 📏 **Filter Panjang** | Pendek / Sedang / Panjang |
| 📅 **Urutan** | Terbaru / Terlama / Terpopuler |
| 📋 **Copy & Download** | Salin atau download prompt dengan 1 klik |
| 🔐 **Admin Panel** | Tambah, edit, dan hapus prompt (login) |
| 🎨 **UI Modern** | Glassmorphism, animasi, responsive |
| 💾 **Auto Save** | Data tersimpan di Local Storage |
